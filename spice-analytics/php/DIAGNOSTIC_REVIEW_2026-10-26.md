# Проверка отчёта ошибок и сохранённой страницы от 26.10.2026

В присланном списке 88 записей: specii.in.ua — 40, Банка спецій — 42,
Deluxe — 4, Spicery Shop — 2. По кодам: `variant_prices_unavailable` — 67,
`price_unknown` — 19, `not_found` — 1, `timeout` — 1.
HTTP 200 подтверждает получение страницы, а не распознавание цены нужного веса.

Сохранённый MHTML «Кумин (зира) молотый» содержит страницу
`https://www.specii.in.ua/catalog/izmelchennye-pryanosti/kumin-zira-molotyy/`.
Фактический запуск текущего парсера под PHP 7.3 прочитал одну цену:

| Признак | Что есть в документе |
| --- | --- |
| Товар | Кумин (зира) молотый |
| Выбранный SKU | `data-treevalue="31_10"`, `bx_active move` |
| Вес и упаковка | Пакет-струна 20 г |
| Цена | `bx_117848907_1326_price`, `content="32.00"` |
| Наличие | `schema.org/InStock` |
| Пакет-струна 500 г | `31_14`, только название |
| Крафт-пакет 500 г | `31_105`, только название |
| Банка 500 г | `31_62`, другой тип упаковки |

Скрытая надпись «Нет в наличии» — часть неактивного интерфейса, а не основание
отменять явный InStock выбранного SKU. Парсер сохранил 20 г, 32 UAH, zip, InStock
и предупреждение, что цены остальных фасовок недоступны. Ручное указание 500 г
не заменило явно прочитанные 20 г. Умножать 32 грн на 25 или приписывать их крафту
нельзя: это не фактическая цена 500 г.

В архиве MHTML 0 скриптов: только HTML, CSS и изображения. Он сохраняет результат
работы страницы для выбранного варианта, но не исходную таблицу цен JavaScript.
Поэтому из него не доказано, сколько стоит крафт-пакет 500 г. Редуцированный
регрессионный пример сохранён в `tests/fixtures/specii-cumin-selected.html`.
Этот этап проверил разметку и существующее чтение выбранной фасовки; полный
сбор остальных цен specii не объявляется исправленным.

## Что нужно для следующего исправления

Нужен исходный HTML с JavaScript, а не ещё один MHTML. Выполнить можно в терминале
Mac или на хостинге, без пароля к магазину и без запросов к админке:

```bash
curl --fail --location --compressed --max-time 45 'https://www.specii.in.ua/catalog/izmelchennye-pryanosti/kumin-zira-molotyy/' --output specii-cumin-source.html
curl --fail --location --compressed --max-time 45 'https://banka-speciy.in.ua/ua/barbaris' --output banka-barbaris-source.html
curl --fail --location --compressed --max-time 45 'https://spiceryshop.com.ua/content/products/kerob-temnyi' --output spicery-kerob-source.html
```

Передать эти три HTML. Первый нужен для таблицы Bitrix SKU и цен. Второй покрывает
другую большую группу ошибок вариантов. Третий — отдельную ошибку отсутствия цены.
Новые страницы не импортируются в аналитику автоматически, они нужны для анализа
структуры и регрессионных тестов. Доступ к конкурентам из рабочего окружения
ограничен его сетевой политикой; обход ограничений не выполнялся.
