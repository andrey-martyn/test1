# Названия, самовывоз и неполные адреса

География относится к заказу и месту его получения, а не к подтверждённому
месту жительства покупателя. Все расчёты выполняются по выбранным периоду,
валюте, статусам, дате проверки и группе по имени. Сырые записи магазина не
переписываются, новые запросы в MySQL не нужны.

## Единый справочник

`src/ukraine-locations.json`: 462 записи названий с областями и 4 948 вариантов
написания. Основа — украинские названия/области evgv/ua-cities (MIT),
альтернативные названия GeoNames из cities-with-1000 1.0.4 (CC BY 3.0),
проверенные дополнения и переименования. Атрибуция и лицензии находятся в
`src/UkraineLocations.LICENSE.txt`, ссылки доступны под картой.

Это справочник распространённых городских названий, а не полный реестр всех
сёл Украины. Источники имеют исторический срез; для переименований включены
проверенные соответствия, включая Дніпро/Днепропетровск,
Чорноморськ/Ильичёвск, Кропивницький/Кировоград и ряд новых названий.
Незнакомые населённые пункты сохраняются как в заказе. При известной области
они уже пригодны для региональной статистики; словарь не требует их исправлять.
Произвольная замена букв или исправление по похожести не применяется.

`GeoNames.php` нормализует регистр, пробелы, апострофы, дефисы, г./м., область /
обл. и распространённые английские варианты. Все 27 административных единиц
имеют единые украинские подписи и ISO-коды. «Одесса»/«Одеса» становятся
«Одеса», «Киев»/«Київ» — «Київ». Киев учитывается отдельно как UA-30,
Киевская область — UA-32; исправлены подписи обоих объектов карты.

Область уточняет одноимённые города. Без области неоднозначное название
(например, Миколаїв) не приписывается областному центру. При отсутствии
известной неоднозначности область может быть восстановлена по справочнику.
Дополнительные одноимённые места GeoNames служат блокировкой такой догадки.
При обычной доставке явная другая страна (например, Odessa, USA) не превращается в Украину.
Префикс села/посёлка не отбрасывается ради совпадения с городом. Противоречие
между известным городом и указанной областью сохраняется для проверки.

Агрегирование идёт по стране, области и каноническому городу. Источник больше
не создаёт вторую строку того же места: он сохранён отдельным счётчиком
`sources`. `variants` и `zone_variants` сохраняют исходные написания и их
число; показываются до 20 вариантов. Поиск понимает исходные названия.
Покупатели считаются заново по разрешённым идентичностям, включая каждый год:
числа покупателей из прежних строк или разных лет нельзя просто складывать.
Каждый заказ попадает ровно в одну строку каждого режима, суммы сохраняются.

## Приоритет источников

1. Явно выбранный самовывоз в Одесе определяет место получения: Одеса,
   Одеська область. Правило действует и при сохранённом другом городе
   покупателя в адресных полях. Это не место жительства; сырые поля не меняются.
2. Для остальных способов — заполненный город и область доставки. В том числе
   адрес отделения Новой почты всегда относится к указанной области получателя.
   Неизвестное справочнику село с заполненной областью не является ошибкой региона.
   Область в скобках после города распознаётся, если это известная область.
3. Частичный адрес доставки с областью сохраняется даже без города.
4. При отсутствии города/области доставки и подходящего самовывоза — адрес оплаты.
5. В смешанном режиме, если нет ни города, ни области, — локальная GeoIP City.
   Известная страна назначения не заменяется другой страной из IP.

Общий «Самовывоз» без города не означает Одесу. Новая Одесса / Нова Одеса,
отрицание и сообщение о недоступности самовывоза не активируют правило.
Для обычной доставки IP не переопределяет явно указанный город или область.
Место самовывоза не доказывает, что покупатель живёт в Одесе.

В режиме адресов используется та же логика без IP. Режим только IP остаётся
отдельной приблизительной оценкой. IP проверяются как публичные; локальные,
некорректные и зарезервированные адреса не геокодируются. Для GeoIP нужен
реальный локальный City MMDB. Его отсутствие/ошибка показаны в интерфейсе.
Ни один адрес IP или покупателя не отправляется во внешние сервисы.

IP показывает сеть подключения на дату базы. VPN, мобильный оператор,
переезд абонента или оформление заказа сотрудником могут дать другой город.
Отделение перевозчика могло бы дать более точное место, но его справочник и
идентификаторы не входят в текущие шесть таблиц загрузки. Назначать город по
коду мобильного телефона или просто переносить его из соседнего заказа нельзя.

## Представление и проверка пропусков

Основная страница показывает доли регионов и сравнение лет, без большого
блока проверки адресов. Подробные города раскрываются по запросу. Режимы
источников, точность и атрибуция находятся в деталях карты. Оставшиеся реальные
пропуски доступны в свёрнутой технической проверке на странице настроек.
Там можно открыть заказ и увидеть сырые поля вместе с итоговой географией.

Неизвестное справочнику название с указанной областью сохраняется и учитывается
в этой области. Оно может остаться в техническом списке названий для пополнения
словаря, но не превращается в ошибку адреса. Счётчики способов доставки и
исходных пропусков по-прежнему доступны в текстовой диагностике.

Новые сравнения: все заказы / без самовывоза / самовывоз; одинаковые даты /
полные годы; до шести регионов и шести лет на вертикальном графике. Полное
описание рекомендаций и их ограничений — [ACTIONABLE_ANALYTICS.md](ACTIONABLE_ANALYTICS.md).

Для текстовой сводки текущей тестовой установки:

```bash
/usr/local/php82/bin/php /home/lavkasp/lavka-speciy.com/analytics-app/spice-analytics/php/bin/check_geography.php --data /home/lavkasp/lavka-speciy.com/analytics-private-test
```

По умолчанию — вся история по сегодняшнюю дату, UAH, все группы по имени.
Дополнительные параметры: `--year 2026 --as-of 2026-10-25 --currency UAH --gender female`.
JSON включает счётчики, способы доставки и объединённые названия, исключает
список заказов, контакты покупателей, IP-адреса и параметры доступа к БД.
Источник и права MySQL не меняются; используется сохранённая закрытая копия.

Ключ кеша отчёта обновлён до `php-v7-loyalty`. Обновление:
обычный pull analytics-demo и `bin/refresh_sandbox.php`. PHP сайта,
конфигурация источника и расписание cron не меняются.

Проверки на синтетике: `php/tests/geography_check.php` под PHP 7.3/8.2,
`geography_browser_check.py` (объединение, источники, поиск по старым названиям,
отдельные Киев/область на карте, просмотр исходного заказа, режимы/IP,
фильтр по имени, 390/320 px), существующие проверки истории, имён и ядра.
