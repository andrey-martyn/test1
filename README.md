# Проекты «Лавка»: общие инструкции

Текущий общий этап — подготовка смены каталогов хостинга. Физический перенос
ещё не подтверждён; рабочие старые пути сохраняются до общего переключения.

- [Единая карта старых и новых путей](HOSTING_PATHS.md)
- [Машинная карта путей](hosting-paths.json)
- [Порядок переноса, отчёт готовности и откат](HOSTING_MIGRATION.md)
- [Инструкции для всех проектов и чатов](AGENTS.md)

Перед адаптацией своего проекта прочитать эти документы. Копии общего контракта
размещены и в рабочих ветках, чтобы его видели все проекты:

| Проект | Ветка |

| Аналитика и Review Factory | [analytics-demo](https://github.com/andrey-martyn/test1/tree/analytics-demo) |
| Мобильные карточки каталога | [codex/mobile-category](https://github.com/andrey-martyn/test1/tree/codex/mobile-category) |

| Метки товаров | [codex/product-tags](https://github.com/andrey-martyn/test1/tree/codex/product-tags) |

Приложения находятся в своих ветках. Для чтения общей инструкции не нужно
заменять ветку действующей установки или сливать её с другим приложением.
