# Лавка — аналитика покупателей, версия 2

Готовое демо и исходники находятся в ветке **analytics-demo**.

## Боевая PHP-версия на обычном хостинге

Для текущего тарифа «Быстрый» подготовлена полная версия: **веб-PHP 7.3 + имеющийся
PHP 8.2 CLI для cron**, без изменения версии PHP магазина, без Python и доплаты.
Имена и контакты доступны после
входа в закрытый HTTPS-кабинет; синхронизация использует отдельного SELECT-пользователя.

Сначала устанавливаем на **`https://test.lavka-speciy.com/analytics/`**, сохраняя
существующую тестовую копию магазина. Поддержан перенос в `/analytics/` основного домена.
Вход, API, статические файлы и отдельная cookie учитывают папку; корневые файлы
OpenCart не меняются. Веб-версия 7.3 подтверждена скриншотом, CLI 8.2 — через SSH.
Для выкладки нужна проверка веб-расширений/HTTPS: `php bin/check_web.php`.
Отдельный поддомен также поддержан.

- [Инструкция установки](spice-analytics/php/README.md)
- [Исходники PHP](spice-analytics/php)
- [Отдельный PHP-комплект lavka-php.zip](lavka-php.zip)

В sandbox проверены все экраны, совпадение расчётов с прежней версией, авторизация,
CRM, резервные копии и настоящая MySQL-синхронизация на синтетических данных.
Реальный хостинг и живая БД ещё не подключены; секреты и рабочая база в Git не включены.

## Как открыть демо

1. На этой странице GitHub нажмите зелёную кнопку **Code**.
2. Выберите **Download ZIP**.
3. Распакуйте скачанный архив `test1-analytics-demo.zip` на компьютере.
4. В корне распакованной папки откройте **lavka-demo-v2.html** двойным щелчком в Chrome.

Этот HTML содержит стили, скрипты и данные внутри себя: сервер и установка не нужны.
Чатовый предпросмотр не требуется. Демо предназначено для просмотра, контакты и IP
покупателей удалены. Суммы и состав заказов сохранены.

![Календарь покупателей — снимок готового демо](docs/dashboard-preview.png)

## Что есть в версии 2

- Календарь по неделям, фильтр числа заказов, 2+/5+/10+.
- Очередь контактов, сегменты и RFM, когорты удержания.
- Повторные покупки, фасовки, товарные пары, ABC и сезонность.
- География адресов и поддержка локальной City MMDB для IP.
- Импорт CSV GA4 и сопоставление транзакций с заказами.

## Полная локальная версия

Исходники — в **spice-analytics/**. Запуск с паролем, настройками, CRM-заметками и
импортом описан в [инструкции](spice-analytics/README.md).
Есть также отдельный комплект **lavka-analytics-v2.zip**.

Демо за 2026 год на 20.10.2026; реальные отчёты GA4 ещё не загружены. Рабочая геобаза
IP пока не установлена. Полная SQL-выгрузка, рабочая БД, контакты и пароли не включены.
