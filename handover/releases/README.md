# Пакет для Игоря — версия 1.0.0-rc1

Все файлы доступны через GitHub. Архив обычный, **без пароля**.

- [Скачать ZIP-пакет](lavka-mobile-cards-1.0.0-rc1.zip)
- [Единая HTML-инструкция](lavka-mobile-cards-1.0.0-rc1-handbook.html)
- [SHA-256 архива](lavka-mobile-cards-1.0.0-rc1.zip.sha256)
- [Читать инструкцию прямо на GitHub](../README.md)

Для скачивания открыть файл ZIP и нажать **Download raw file** (стрелка вниз).
После распаковки начать с `HANDBOOK.html` или `README.md` внутри архива.
Инструкция разделена на изменения, сверку файлов, перенос, приёмку,
откат, условную очистку CSS в БД и ориентиры ручного объединения.

В пакете шесть конечных файлов магазина, четыре исходных для сравнения,
полный diff, manifest и проверка файлов без записи. Конфигов, паролей,
клиентских данных, дампов и кэшей нет. Архив не запускает установку.

Код подготовлен на версии `74d9b07` и включает `font-weight:100` с CSS URL `?v=2`.
Подробные сведения о проверках и ограничениях находятся внутри.
Документация и пакет не являются подтверждением обновления рабочего сайта.
