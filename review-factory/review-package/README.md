Учебный прототип отдельного модуля для внутренней инженерной проверки. Исходники в пакете зафиксированы на коммите [e064486](https://github.com/andrey-martyn/test1/commit/e064486728f0a63133c0e8ab03006dba6a9abd9f) ветки analytics-demo.

После распаковки открыть **00_START_HERE.html** или **REVIEW_SUMMARY.pdf**. Архив предназначен для изучения, его не нужно загружать в установщик расширений ocStore.

Внутри: исходники фиксированной версии и три зависимости аналитики, два diff, архитектура, карта файлов, свежие логи локальных проверок, тестовые скриншоты, чек-лист ревью, шаблон замечаний, запуск локально и порядок проверки/отката на TEST.

## Границы проверки

22 локальных запуска прошли; выполнено 517 проверок с повторами на PHP 7.3/8.2. Синтаксис PHP 7.3 проверен в 35 файлах. Реальная установленная UniShop2, её Twig-шаблоны, кеши и запуск на хостинге требуют отдельной проверки программистом.

Это явно помеченные синтетические данные и отдельная TEST-интеграция. Покупательские отзывы, их рейтинг и поисковая разметка не изменяются демо-потоком. Архив не содержит реальных клиентских баз, паролей, рабочих конфигураций и сессий.

Код модуля для просмотра непосредственно в GitHub: [review-factory/](../). Последняя интеграция выделена внутри ZIP в diff/01-demo-addon.patch; полный модуль — в source/review-factory/.
