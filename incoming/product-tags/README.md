# Исходники для задачи тегов

Загружать сюда только файлы тестового магазина. Полный список и предварительный
разбор — [PRODUCT-TAGS-ANALYSIS.md](../../docs/PRODUCT-TAGS-ANALYSIS.md).

- `source/` — исходники с путями относительно `/lavka-speciy.com/test/`.
  Например: `source/admin/controller/catalog/product.php`.
- `diagnostics/modification/` — только нужные действующие OCMOD-копии из
  `test_storage/modification/`, если исходного XML пока нет. Не смешивать с source.
- `diagnostics/styles/` — только указанные generated/merged CSS для сверки.

Файлов исходных моделей `catalog/model/extension/module/uni_new_data.php` и
кода админки ранее не было в предоставленном архиве; они нужны в первую очередь.
Если какой-то путь отсутствует или называется иначе, указать это ниже.

Не загружать config.php, пароли, ключи, лицензию, БД, cache/logs/session или
storage целиком. Рабочий сайт не выгружать. Диагностические сгенерированные
файлы нужны только для чтения; код дорабатывается в исходниках.
