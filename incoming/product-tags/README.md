# Исходники для задачи меток

Архив `222.zip` получен 28 октября 2026. Нужные исходники импортированы в
`store/` с путями магазина, исходная версия — коммит `647cb88`.
Происхождение и хеши: [product-tags-source.json](../../docs/product-tags-source.json).

Повторная загрузка этих файлов не требуется. Если проверка на хостинге
выведет `SOURCE_HASH_MISMATCH`, нужен только указанный отличающийся исходник
из тестовой установки для ручного объединения. Нельзя обходить проверку
или брать сгенерированную OCMOD-копию как основной исходник.

Не загружать сюда config.php, пароли, ключи, лицензию, БД, cache/logs/session,
storage целиком или файлы рабочего сайта. Архив содержал конфиг: он исключён
из выбранных исходников и Git.
